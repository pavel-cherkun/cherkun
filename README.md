# CHERKUN™ — Creative Compute Unit

Сайт-портфолио Павла Черкуна, креатора для рекламных тендеров: https://pavel-cherkun.github.io/cherkun/

Статика без сборки: `index.html`, 3D-юнит на Three.js (`unit/unit.js`), данные кейсов в `cases.js`, медиа в `media/`.
Исходники и рабочие файлы лежат локально в `pf/redesign/`, эта папка собирается из них.
